# Shit Debug

高效 debug 的临时解决方案 - 浏览器扩展

## 功能列表

### 🔧 自动填充

智能识别页面表单并自动填充测试数据：

- 支持文本输入框、文本域
- 支持 Element Plus 日期选择器（DatePicker）
- 支持 Element Plus 下拉选择器（Select）
- 支持 Element Plus 级联选择器（Cascader）
- 支持文件上传（自动生成测试图片）
- 智能识别字段类型（手机号、姓名、邮箱、身份证、日期、年龄等）
- 支持跨 iframe 填充
- 跳过已有内容的字段

### 📄 API 文档提取

从文档页面批量提取 API 文档：

- 框选 `ul` 或 `li` 元素
- 自动识别叶子节点中的链接
- 批量提取链接对应页面的内容
- 支持单个下载或打包成 ZIP 下载

### 🔍 页面 iframe 检测

检测并管理页面中的 iframe：

- 自动检测页面内所有 iframe
- 显示 iframe 的 Hash 内容
- 支持获取 OpenKey 并替换 URL
- 一键打开所有 iframe 或单独跳转

### 🔑 OpenKey 获取

快速获取当前页面的 OpenKey：

- 自动捕获请求配置
- 一键获取并复制到剪贴板

### 🚫 广告屏蔽

临时屏蔽页面广告弹窗：

- 设置 localStorage 过期时间
- 有效期 8 小时

### 🔎 导航搜索

在页面导航中快速搜索：

- 搜索包含指定文本的导航项
- 自动点击匹配的导航
